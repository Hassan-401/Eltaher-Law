# مكتب الطاهر للمحاماة والاستشارات القانونية والعقارية

موقع تعريفي عربي (RTL) لمكتب الطاهر للمحاماة — مدينة بدر، القاهرة.
موقع ثابت بالكامل (HTML/CSS/JS) بدون أي إطار عمل أو قاعدة بيانات، جاهز للرفع على أي استضافة.

**الرابط:** _(أضف رابط الموقع بعد النشر)_

## المحتوى

| القسم | العدد |
|---|---|
| الصفحات الرئيسية | 5 (رئيسية، عن المكتب، مجالات العمل، المقالات، تواصل معنا) |
| صفحات مجالات العمل | 12 |

مجالات العمل: الجنايات، الجنح والمخالفات، الأحوال الشخصية والأسرة، المدني، التعويضات، الضرائب،
العقاري، الشركات والعقود، العمالي، الإداري، التنفيذ والتحكيم، الاستشارات القانونية.

## التعديل وإعادة البناء

ملفات الـHTML **مُولَّدة** من مجلد `build/` حتى لا يتكرر الهيدر والفوتر في 26 ملف يدويًا.

### لتعديل بيانات المكتب (تليفون، عنوان، مواعيد)

عدّل `build/data/site.js` ثم شغّل:

```bash
node build/build.js
```

كل الصفحات الـ26 تتحدث تلقائيًا.

### لإضافة مقال جديد

أضف عنصرًا جديدًا في `build/data/articles.js`:

```js
{
  slug: 'article-url-name',        // اسم الملف
  title: 'عنوان المقال',
  excerpt: 'ملخص سطرين يظهر في البطاقة',
  category: 'جنائي',                // يظهر في فلتر التصنيفات
  service: 'ganayat',               // المجال المرتبط (اختياري)
  date: '2026-08-01',
  body: `<p>محتوى المقال بصيغة HTML...</p>`
}
```

ثم `node build/build.js`. زمن القراءة والترتيب والتصنيف تُحسب تلقائيًا.

### لإضافة أو تعديل مجال عمل

عدّل `build/data/services.js` بنفس الطريقة، ثم أعد البناء.

> **ملاحظة:** لو عدّلت ملف HTML مباشرة، التعديل هيضيع عند تشغيل المولّد.
> عدّل من `build/data/` دائمًا.

## النشر

ارفع محتويات المجلد كما هو (ما عدا `build/`) على أي استضافة ثابتة:
GitHub Pages، Netlify، Vercel، أو أي استضافة تقليدية عبر FTP.

لا يحتاج المشروع أي بناء على السيرفر ولا Node.js في بيئة الإنتاج —
Node مطلوب فقط على جهازك عند تعديل المحتوى وإعادة التوليد.

## مزايا تقنية

- تصميم عربي RTL بالكامل، متجاوب مع الموبايل والتابلت والديسكتوب.
- نموذج التواصل يرسل الرسالة مباشرة إلى **واتساب المكتب** — بدون سيرفر أو باك-إند.
- لافتة "المكتب مفتوح الآن / مغلق حاليًا" تتغير تلقائيًا حسب توقيت القاهرة.
- بيانات Schema.org لتحسين الظهور في البحث (LegalService / Service / FAQPage / Article).
- `sitemap.xml` و `robots.txt` جاهزان.
- خطوط Cairo و Tajawal من Google Fonts.
